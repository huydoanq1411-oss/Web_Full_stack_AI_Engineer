Algorithm Mastery — Cheat Sheet

Array — tìm kiếmO(n)
Linked List — chèn đầuO(1)
Linked List — tìm kiếmO(n)
Hash Table — tra cứu (avg)O(1)
Hash Table — worst caseO(n)
BST cân bằng — tìm/chèn/xóaO(log n)

🧩 Template — Backtracking

def backtrack(state, choices, res): if is_solution(state): res.append(list(state)); return for c in choices: if is_valid(state, c): state.append(c) backtrack(state, next(state), res) state.pop() # quay lui

🧩 Template — DP Bottom-Up

dp = [base_case] * (n + 1) for i in range(1, n + 1): for choice in choices: dp[i] = best(dp[i], dp[i-choice] + cost) return dp[n]

🧩 Template — BFS

from collections import deque def bfs(start): q = deque([start]); visited = {start} while q: node = q.popleft() for nxt in graph[node]: if nxt not in visited: visited.add(nxt); q.append(nxt)

🧩 Template — Binary Search

def binary_search(arr, target): lo, hi = 0, len(arr) - 1 while lo <= hi: mid = (lo + hi) // 2 if arr[mid] == target: return mid elif arr[mid] < target: lo = mid + 1 else: hi = mid - 1 return -1

💡 Ghi nhớ nhanh trước phỏng vấn

DP = Optimal Substructure + Overlapping Subproblems Greedy = Greedy Choice Property + Optimal Substructure Dijkstra ≠ trọng số âm → dùng Bellman-Ford MST cạnh = V - 1 Euler = mọi đỉnh bậc chẵn Hamilton = NP-Complete Fractional Knapsack → Greedy | 0/1 Knapsack → DP Union-Find: Path Compression + Union by Rank
