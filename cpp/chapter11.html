11 Con trỏ & Tham chiếu

Hai khái niệm đặc trưng và quan trọng nhất của C++ — thao tác trực tiếp với địa chỉ bộ nhớ.

Con trỏ (Pointer)

pointer.cpp 
int so = 10;
int* con_tro = &so;    // & = lấy ĐỊA CHỈ của biến "so"

cout << so << endl;             // 10 - giá trị của so
cout << &so << endl;              // địa chỉ bộ nhớ của so (dạng 0x...)
cout << con_tro << endl;           // cùng địa chỉ đó - con_tro LƯU địa chỉ
cout << *con_tro << endl;           // 10 - * = "dereference", lấy GIÁ TRỊ tại địa chỉ đó

*con_tro = 99;    // thay đổi giá trị THÔNG QUA con trỏ
cout << so << endl;   // 99 - biến gốc "so" cũng bị thay đổi!

Tham chiếu (Reference)

reference.cpp 
int so = 10;
int& tham_chieu = so;    // tham_chieu là một "BÍ DANH" khác của so, không phải biến riêng

tham_chieu = 20;
cout << so << endl;   // 20 - thay đổi tham chiếu = thay đổi biến gốc luôn
Tiêu chíCon trỏ (Pointer)Tham chiếu (Reference)

Cú pháp truy cậpCần * để lấy giá trịDùng trực tiếp như biến thường
Quan trọng
Con trỏ là nguồn gốc của rất nhiều lỗi kinh điển trong C++: dangling pointer (trỏ tới bộ nhớ đã giải phóng), memory leak (quên giải phóng bộ nhớ đã cấp phát). Luôn khởi tạo con trỏ với nullptr nếu chưa trỏ tới đâu, và kiểm tra trước khi dùng.

Con trỏ lưu địa chỉ bộ nhớ, có thể đổi trỏ và có thể null. Tham chiếu là bí danh cố định của một biến, an toàn hơn nhưng kém linh hoạt hơn con trỏ.
